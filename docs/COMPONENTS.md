# Raven Core Components

## ActionButton
* Background: `#000000`
* Text Color: `#FFFFFF`
* Border Radius: `9999px`
* Padding: Vertical `16px`, Horizontal `24px`
* State: Disabled = `opacity: 0.5`

## OutlineButton (e.g., Counter Offer)
* Background: `transparent`
* Border: `1px solid #000000`
* Text Color: `#000000`

## TrackingBar (Chat Screen)
* Nodes: `12px` by `12px` circle.
* Active Node: `#000000` background.
* Inactive Node: `#E5E7EB` background.
* Connecting Line: `1px` height, `#E5E7EB`.
