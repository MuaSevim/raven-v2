# Raven Design System

## Core Aesthetic
Monochromatic, minimalist, "Uber-like". High contrast, low friction. No gradients. No unnecessary borders.

## Color Palette
* Primary Background: `#FFFFFF` (White)
* Primary Surface: `#F9FAFB` (Light Gray - for cards)
* Primary Text: `#000000` (Black)
* Secondary Text: `#6B7280` (Medium Gray)
* Action/Primary Element: `#000000` (Solid Black)
* Error: `#EF4444` (Red - use sparingly)
* Success/Tracking: `#000000` (Solid Black) - DO NOT USE GREEN.

## Typography
* Font Family: `Inter`
* Headings: `font-weight: 700`, `letter-spacing: -0.5px`
* Body: `font-weight: 400`
* Labels/Caps: `font-weight: 600`, `text-transform: uppercase`, `letter-spacing: 1px`

## Spacing & Metrics
* Base Unit: `8px`
* Standard Padding: `16px` or `24px`
* Border Radius (Standard): `8px`
* Border Radius (Pills/Buttons): `9999px` (Fully rounded)
